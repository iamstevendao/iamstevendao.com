# iamstevendao.com

Bun + Vite + React + shadcn/ui, deployed to Cloudflare Workers static assets.

```bash
bun install
bun run dev      # http://localhost:5173/?variant=A|B|C (prototype switcher, dev only)
bun run deploy   # build + wrangler deploy
```
